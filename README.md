
## Instalación

Para instalar el proyecto, primero cloná el repositorio.

Después ejecutá el siguiente comando:


```bash
git clone git@github.com:Unnisemai/dotfiles.git
cd dotfiles
./install.sh
```

NANANA MIRA COMO TE VA AQUEDAR
